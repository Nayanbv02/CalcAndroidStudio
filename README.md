# Calculadora en Java con layout XML

Este proyecto es una **calculadora básica** desarrollada en **Java** utilizando un layout **XML**. 
La aplicación permite realizar una operación de suma entre dos números ingresados por el usuario. 
Este proyecto es un ejemplo para aprender sobre la creación de interfaces gráficas modernas en Android utilizando java y xml.

---

## Funcionalidades
- Interfaz gráfica simple con un layout XML.
- Dos campos de entrada para ingresar números a sumar.
- Botón para realizar la operación de suma.
- Mensajes de error si se ingresan datos inválidos (no numéricos).
- Resultado mostrado directamente en la pantalla.
